# deep_reversal_bot

**Резервные лимитки на глубоких уровнях + подтверждение отскока**

Ставит GTC-лимитки на 0.01 и 0.02 (обе стороны). После исполнения ждёт 15с. Если цена отскочила ≥ 0.005 — держит до резолва. Иначе аварийно продаёт FAK.

Валидировано только на BTC/15m.

## Запуск
```bash
python deep_reversal_bot.py
```
