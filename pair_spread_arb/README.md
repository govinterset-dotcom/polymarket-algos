# pair_spread_arb_bot

**Спред-арбитраж между парами активов** (по умолчанию BTC:SOL и ETH:SOL) на одном и том же live-окне 5m/15m.

- Независимые пороги спреда (каждый срабатывает один раз на рынок)
- Нога A: дешёвая Up-сторона
- Нога B (опционально): Down дорогой стороны
- FAK с добором остатка и эскалацией цены

## Запуск
```bash
PAIRS="BTC:SOL,ETH:SOL" python pair_spread_arb_bot.py
```
