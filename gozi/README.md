# Gozi — Late Strong Impulse

**Tags:** `impulse` · `late-window` · `5m` · `volume-progression` · `limit`

Catches a strong mid-price impulse in the final ~30 seconds of a BTC Up/Down 5-minute market: the side started cheap, then jumped hard. Places a limit buy only when the ask is still elevated (filters false moves). Includes a volume-progression cycle after accepted fills.
